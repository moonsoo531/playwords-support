プライバシーポリシー

PlayWords / 更新日：2026年10月10日

PlayWordsは、iPhone・iPad・Macで英語のスペルを練習するアプリです。以下では、現在のアプリが学習データをどのように扱うかを説明します。

運営者：Wen Zhao

1. 端末に保存するデータと利用目的

ユーザーが入力・読み込んだ単語帳、単語、意味、例文、訳、メモなどの教材を端末のアプリ用データベースに保存します。学習を続けられるよう、入力した回答、正誤、ヒントの使用、回答時間、復習予定、学習日時、スコア、経験値、成長の記録も保存します。

これらの情報は、問題の出題、復習時期の調整、学習履歴や成長の表示、バックアップと復元のために使います。表示言語、学習量、音量、Game Centerの利用設定などは端末の設定データとして保存します。

PlayWords独自のユーザーアカウントを作成する機能はありません。アプリ内でApple Accountのパスワードを入力させることもありません。

現在のアプリには広告配信SDK、広告識別子を使うトラッキング、独自の利用解析サービスは組み込んでいません。学習統計の表示や任意のGame Centerランキングで使う学習記録は、以下の説明に従って扱います。

2. iCloudによる同期

配布版はAppleのCloudKitを使用します。端末でiCloudが有効で利用可能な場合、教材、学習進捗、履歴などのアプリデータを、そのiCloudアカウントに対応するプライベートデータベースと同期します。同じiCloudアカウントの端末間で学習を続けるための機能です。

現在のアプリにはiCloud同期専用のオン・オフ切替はありません。iCloudの利用は端末のシステム設定とAppleの提供条件に従います。端末に保存済みのデータはオフラインでも利用でき、再接続後に同期が行われます。同期は即時ではありません。

PlayWordsの独自サーバーへ教材や学習履歴を送信する機能はありません。iCloudサービスでAppleが取り扱う情報は、Appleのプライバシーポリシーと各サービスの説明をご確認ください。

3. 任意のGame Center接続

Game Centerは初期設定でオフです。ユーザーが「学習設定」で「Game Center を利用する」をオンにした場合に、AppleのGame Centerへ接続します。必要な認証はAppleの画面で行います。Game Centerを使わなくても学習とiCloud同期は利用できます。

接続すると、ランキングのために習得単語数、新しく学習した単語数、学習時間の整数スコアをGame Centerへ送信します。アプリは、Game Centerのプレイヤー識別子、表示名、順位、スコアを使用し、希望する場合は友達のランキングを表示します。Game Centerの表示名やスコアは、利用するランキングの範囲で他のユーザーに表示される場合があります。

アプリの設定をオフにすると、PlayWordsからの新しいランキング送信・取得や友達リクエストを停止します。端末のGame Centerアカウントからのサインアウトや、すでに送信したスコアの削除を行う操作ではありません。Apple側の情報の管理については、Game Centerとプライバシーをご確認ください。

4. 読み込んだファイルとバックアップ

ユーザーが選択したCSV・TSV・Excel（.xlsx）の教材ファイル、貼り付けたテキスト、.playwordsのバックアップを端末で読み取り、内容を確認してからアプリに取り込みます。保存した教材や学習データは、iCloudが利用可能な場合には同期の対象になります。

CSV書出しや完全バックアップの保存先・共有先はユーザーが選択します。.playwordsの完全バックアップには教材、学習進捗、入力記録や学習履歴などが含まれるため、共有先と保管場所を確認してください。アプリ外に保存・共有したファイルは、アプリ内の教材を削除しても自動では削除されません。

現在のアプリは写真・動画・録音の教材読込や、カメラ・マイクを使った収集を行いません。

5. Appleのシステム機能と外部リンク

英語の読み上げには端末のシステム音声機能を使用します。発音記号はアプリに同梱した辞書データから参照します。ファイル選択、保存、共有、iCloud、Game CenterはAppleのシステムやサービスを利用します。

発音データの出典・ライセンスなどの外部リンクを開くと、リンク先のサービスの方針が適用されます。単語ごとのWiktionary出典リンクを自分で開く場合は、選択した単語を含むURLにアクセスします。App Store、TestFlight、Appleの診断共有設定などで取り扱われる情報については、Appleのプライバシーポリシーをご確認ください。

6. 保存期間、削除とユーザーの選択

教材や学習データは、継続学習や履歴表示のために保存します。単語や単語帳をアプリ内で編集・削除でき、「最近削除した項目」から復元することもできます。復元可能な期間は通常30日で、期限切れの項目はアプリのメンテナンス処理時に削除されます。手動で完全削除する機能もあります。

教材の完全削除では関連する単語内容や直接の入力記録などを削除しますが、教材の生テキストを含まない学習集計や成長記録の一部は残る場合があります。現在のアプリには、すべての学習集計・iCloudデータ・Game Centerスコアを一括で消去する操作はありません。

iCloudが利用可能な場合、アプリデータの変更・削除も同期の対象になります。ただし、アプリのアンインストールだけでiCloud上のデータや既存のバックアップが削除されるとは限りません。端末外のデータやApple側の情報の管理は、それぞれのサービスの設定と説明に従ってください。

Game Centerの利用は「学習設定」で取り消せます。データの扱いについて質問がある場合は、下記の窓口をご利用ください。

8. ウェブサイトの配信とアクセス情報

このウェブサイトはGitHub Pagesで配信します。これらのページにはJavaScript、独自のアクセス解析、広告トラッカーを設置していません。

GitHub Pagesへのアクセス時は、GitHubへのサインインの有無にかかわらず、訪問者のIPアドレスがセキュリティ目的でGitHubにより記録・保存されます。詳細はGitHub Pagesのデータ収集の説明とGitHubのプライバシーに関する声明をご確認ください。
